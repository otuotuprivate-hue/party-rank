# Party Rank点数評価ツール

ログイン不要で誰でも使えるWebサイトです。依存パッケージはなく、Node.js 18以上だけで動きます。

## 動かし方(自分のパソコンで試す)

```
cd party-rank
ADMIN_NAME=taetae ADMIN_PASSWORD=好きなパスワード node server.js
```

http://localhost:3000 を開きます。

## 公開する前に必ずやること

1. **管理者パスワードを変える。** 初期値は `taetae` / `Taiga0119` です。
   環境変数 `ADMIN_NAME` と `ADMIN_PASSWORD` は **最初の起動時だけ** 使われます。
   すでに起動したあとで変えるときは、サーバーを止めて次を実行します。
   `node set-admin.js taetae 新しいパスワード`
2. **データの保存場所を永続ディスクにする。** データは `DATA_DIR`(既定は `./data`)の `db.json` に保存されます。
   ディスクが消えるサービス(無料プランなど)では、永続ボリュームを付けないと再起動でデータが消えます。
3. **HTTPSで公開する。** 下の各サービスは自動でHTTPSになります。
   リバースプロキシの内側で動かすときは `TRUST_PROXY=1` を設定します(ログイン試行の回数制限が正しい接続元で数えられます)。

## 公開先の例

| 方法 | 手順の目安 |
| --- | --- |
| Render / Railway / Fly.io | このフォルダをGitHubに置く → 新しいWebサービスを作る(Docker または Node)→ 永続ディスクを `/data` に付ける → 環境変数 `DATA_DIR=/data` `TRUST_PROXY=1` `ADMIN_NAME` `ADMIN_PASSWORD` を設定 |
| 自分のVPS | `node server.js` をsystemdなどで常駐させ、Caddy や nginx でHTTPS化する |
| Docker | `docker build -t party-rank .` → `docker run -p 3000:3000 -v prdata:/data -e ADMIN_PASSWORD=... party-rank` |

## 使い方

- **参加者**: 名前を入力して参加 → 曲一覧で点数(0〜10・0.5点刻み)を選ぶ → ☆は各クールで1曲だけ。
  合言葉(任意)を決めておくと、別の端末から同じ名前で続きを採点できます。
  他の参加者のランキングは、本人と管理者しか見られません(管理者以外には返さない作りです)。
- 参加者は、自分の名前を「名前を変更」でいつでも変えられます。曲ごとに「ひとこと」(100字まで)も書けます。ひとことを見られるのは本人と管理者だけで、CSV・JSONには入りません。
- **管理者**: 「管理者画面に入る」から入ります。ログインは12時間で切れます。できること:
  - 曲の追加・**編集**・削除
  - 区分ごとの **iTunes(Apple Music)プレイリストのURL** の登録(管理者だけが貼れます。リンクは参加者にも表示されます。`music.apple.com` などのURLだけ受け付けます)
  - 全ユーザーの全体表とひとことの確認、データの書き出し
  - **参加者の削除**(その人の点数・☆・ひとことも消えます)
  - 管理者の追加(パスワード6文字以上)

## ランキング動画ツール向けのデータ

管理者画面の「動画用CSV」「動画用JSON」で、区分(例: 2026年秋OP)ごとに書き出します。
「順位の低い順に並べる」にチェックすると、発表用に下位から並びます。

### JSONの形

```json
{
  "key": "2026-10-OP",
  "label": "2026年秋OP",
  "order": "rank-asc",
  "participants": ["alice", "bob"],
  "participantAverages": { "alice": 8.25, "bob": 7.25 },
  "overallAverage": 7.75,
  "items": [
    { "rank": 1, "title": "曲名", "artist": "アーティスト", "anime": "作品名",
      "average": 8, "scoreCount": 2, "stars": ["alice"],
      "scores": { "alice": 7.5, "bob": 8.5 } }
  ]
}
```

- 順位は平均点の高い順で、小数第3位まで同じ平均なら同順位です。誰も採点していない曲は `rank: null` で最後に並びます。
- 動画用CSVは1行目が見出し、2行目以降が曲です(順位, 曲名, アーティスト, アニメ作品名, 平均点, 採点人数, ☆の数, 各ユーザーの点数…)。文字コードはUTF-8(BOMつき)です。
- 「全体表CSV」は管理者画面の表と同じ内容で、最後に「ユーザーの平均」と「☆」の行が付きます(人が読む用)。
- 管理者としてログインした状態なら、`/api/admin/export?key=2026-10-OP&format=json` を直接呼ぶこともできます(`Authorization: Bearer <管理者トークン>`)。区分を `all` にすると全区分をまとめて取れます(JSONのみ)。

## 構成

- `server.js` … サーバー本体(APIと静的ファイル)
- `public/` … 画面(index.html / app.js / style.css)
- `set-admin.js` … 管理者パスワードの設定・追加
- `data/db.json` … 保存データ(自動で作られます。バックアップはこのファイルをコピーするだけです)

## 追加機能(管理者画面)
- 曲の並び替え: 曲一覧の各行の「↑」「↓」(参加者の画面の並びも同じになります)
- 年の追加: 「年の追加」で1950〜2100の年を選べるようにします(曲のある年は削除不可)
- アップデート情報: 「アップデート情報の記載」から投稿・削除。全員の画面上部に表示されます
- 一般ユーザー画面は、最後に開いた年・クール・OP/EDを次回も開きます(各自のブラウザに保存)

## 追加機能 その2
- 参加者一覧: 画面上部の「参加者一覧」(全体のユーザーと、ランキングごとの参加者・採点数。点数は見えません)
- 削除の確認画面: 曲・ユーザー・お知らせ・年の削除は、確認の画面で「削除する」を押すまで実行されません
- 提出期限: 管理者画面で区分ごとに設定。一般ユーザーには「提出期限・残り時間」を表示(表示のみで、期限後も採点できます)
- 全体表の並べ替え: 管理者画面の表で、ユーザー名(または「曲の平均」)をクリックすると点数順に並び、もう一度で逆順、3回目で元の順位順

## メニューバー更新

**一般ユーザー画面のメニュー**: ホーム / ユーザー名の変更(合言葉が必要) / パスワード(合言葉)の再設定(現在の合言葉が必要) / 参加者一覧(ランキングはプルダウンで選択) / 管理者画面への入室(パスワード画面へ移動)。
**管理者画面のメニュー**: 管理者ホーム / 管理者一覧 / 一般ユーザーのパスワードリセット / 管理者パスワードの変更(現在のパスワードが必要) / アップデート情報の登録 / 管理者画面からの退出(一般ページへ戻る)。
メニューで選んだ機能は1ページずつ表示されます(ブラウザの「戻る」も使えます)。

注意:
- 合言葉を未設定のユーザーは、先に「パスワード(合言葉)の再設定」で合言葉を決めると、名前を変更できます。
- 管理者によるリセットは、管理者が仮の合言葉(4文字以上)を入力して本人に伝える方式です。そのユーザーの現在のログインは解除されます。
